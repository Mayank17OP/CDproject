How it works

The analyzer uses the classic Stack algorithm in a single pass — O(n) time, O(n) space:

  1. Read each character left to right.
  2. If it is an opening bracket ( [ { — push it onto the stack.
  3. If it is a closing bracket ) ] } — check the top of the stack: if it matches, pop it; otherwise report a mismatch.
  4. At the end, the string is balanced only if the stack is empty.
pairs = { ')':'(', ']':'[', '}':'{' }
stack = []
for ch in input:
    if ch is opening: stack.push(ch)
    elif ch is closing:
        if stack.top matches ch: stack.pop()
        else: error!
balanced = (stack is empty)

Optional pairs: angle brackets <> and quotes "" '' `` can be enabled above. Everything runs locally in your browser — no data ever leaves your device.
